## Overview

This project provides an all-in-one focus dashboard designed to help users structure their workday. Built with Next.js and TypeScript, it supports full GitHub authentication via Auth.js alongside a **read-only Demo Mode** that allows instant exploration without account creation.

### Features

- **Habit Tracker:** Create and track daily habits.
- **Todo List:** Create, check off, and delete tasks.
- **Active App/Site Blocker Session Display:** View the actively running App/Site Blocker sessions along with a live time remaining display.
- **Authentication & Access Control:** Login via Github OAuth (with protected routing), or explore instantly using a read-only **Guest Demo Mode** that lets you try out the app without mutating the database.

## 🐳 Docker & AWS Infrastructure

This application is fully containerized and deployed to AWS via an automated CI/CD pipeline.

### Container Architecture

- **Dockerfile:** Multi-stage build leveraging Node.js slim images to minimize production image size and speed up deployment steps.
- **Docker Compose:** Configured for quick local development parity and service orchestration.

### CI/CD Deployment Flow

[ Developer ] ── push ──► [ GitHub Repo ]
│
▼
[ GitHub Actions Runner ]
├── 1. Quality Checks (ESLint, Prettier, TypeScript Compiler)
├── 2. Automated Tests (Vitest)
├── 3. Build Production Image
├── 4. Authenticate & Push to AWS ECR
└── 5. SSH into AWS EC2 ──► Pull latest image ──► Restart Container

1. **Amazon ECR (Elastic Container Registry):** Serves as the private registry storing versioned Docker images generated by CI runs.
2. **Amazon EC2:** Hosts the running Docker container inside an isolated security group, exposing traffic to the web.

## Local Development

### Prerequisites

Development Environment (Tested & Verified):

- **Node.js:** v26.4.0+ (Container runs `node:26.5.0-slim`)
- **pnpm:** v10.28.0+
- **Docker Engine:** v29.6.2+ (optional, for containerized local runs)
- **Docker Compose:** v5.3.1+ (optional, for containerized local runs)
- A NeonDB PostgreSQL connection string
- A Github OAuth Application Client ID and Secret

### Option A: Standard Setup

1. **Clone & Install**

   ```bash
   git clone https://github.com/Lushtrii/productivity-dashboard.git
   cd productivity-dashboard
   pnpm install
   ```

2. **Configure Environment Variables**
   Create a `.env.local` file in the root directory:

   ```
   DATABASE_URL="postgresql://user:password@endpoint.neon.tech/neondb?sslmode=require"
   AUTH_SECRET="your-auth-js-secret"
   AUTH_GITHUB_ID="your-github-oauth-client-id"
   AUTH_GITHUB_SECRET="your-github-oauth-client-secret"
   ```

3. **Run Development Server**
   `pnpm dev`

Open http://localhost:3000 in your browser.

**Option B: Running via Docker Compose**

If you prefer not to manage local Node environments:

    Create a .env.local file with the required variables as shown above.

    Build and spin up the containerized app:
    ```bash
    docker compose up --build nextjs-dev
    ```

The app will be accessible at http://localhost:3000.
